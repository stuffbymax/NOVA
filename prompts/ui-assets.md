# Strategy-game UI asset sheet

Create a clean transparent-background asset sheet for NOVA containing [ASSET
LIST]: resource icons, fleet markers, population markers, diplomacy symbols,
planet class icons, technology icons, and notification badges. Use a unified
silhouette language, consistent stroke weight, strong contrast, and a
restricted palette of [COLORS]. Every icon must remain recognizable at 32x32
and 64x64 pixels.

Arrange assets in an orderly grid with generous spacing, but include no text,
numbers, letters, logos, or UI panels. Produce original symbols that can be
used in a 2D science-fiction grand-strategy interface.

Append the shared style in [visual-style.md](visual-style.md), simplified for
small icon readability.
