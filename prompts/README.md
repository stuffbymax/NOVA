# NOVA image prompts

These prompts define a consistent visual language for concept art and production
assets. Keep generated images as references until they are reviewed and added
to the game's asset pipeline.

## Shared style

Use the shared style block from [visual-style.md](visual-style.md) at the end
of each prompt. Replace bracketed fields with the subject-specific details.
Request a clean 2D game asset, readable at a glance, with no text or logos.

## Civilization archetypes

Use these as starting points in [civilizations.md](civilizations.md), then
combine an archetype with a government, technology level, visual motif, and
homeworld:

- Humanoid: adaptable tool users, varied cultures, expressive faces, practical
  clothing, frontier or imperial styling.
- Aquatic: amphibious or ocean-dwelling people, translucent materials, fins,
  gills, bioluminescence, pressure-resistant architecture.
- Insectoid: chitin, segmented anatomy, caste variation, hive coordination,
  organic geometry, communal architecture.
- Avian: feathered or winged people, light skeletal silhouettes, aerial cities,
  plume-based status symbols, high-altitude environments.
- Reptilian: scaled people, heat-conscious clothing, angular armor, desert or
  volcanic origins, ancient ceremonial motifs.
- Mammalian: furred or horned people, strong clan identity, layered garments,
  cold-world or forest-world adaptations.
- Fungal: spore-based beings, mycelial networks, soft organic shapes, luminous
  caps, symbiotic technology.
- Synthetic: robots, androids, or distributed machine minds, modular bodies,
  visible interfaces, manufactured habitats, no biological assumptions.
- Energy or crystalline: non-humanoid luminous entities, crystal structures,
  geometric bodies, unusual light-based communication.
- Lithoid: mineral-based beings, carved stone anatomy, subterranean origins,
  geological color palettes, massive industrial forms.
- Molluscoid: tentacles, shells, soft-bodied silhouettes, tidal or reef
  cultures, fluid gestures, elegant pressure-suit design.

Avoid copying named franchises, logos, or distinctive character designs. Build
original combinations from these broad archetypes.
