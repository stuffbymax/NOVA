# Shared NOVA visual style

NOVA cinematic 2D illustrated space grand-strategy game art with realistic,
three-dimensional-looking rendering. The final image must remain a hand-painted
2D asset, not a 3D model render, not flat vector art, and not pixel art.
Use physically plausible materials, atmospheric perspective, spherical
lighting, soft rim light, cast shadows, metallic surfaces, deep nebulae,
volumetric glow, fine surface detail, and believable scale to create 3D-like
depth on a 2D canvas.

Use dark navy and charcoal space, restrained teal and warm amber accents,
strong focal points, painterly brushwork, layered shading, and clean
silhouettes that remain readable in a strategy interface. Original designs
only; no text, labels, watermark, frame, UI panels, or recognizable franchise
designs.
